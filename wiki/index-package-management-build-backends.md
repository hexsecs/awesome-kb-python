# Package Management / Build Backends

- [setuptools](setuptools.md) — The historical and still most widely used pyproject build backend.
- [hatchling](hatchling.md) — Modern, extensible build backend from the hatch project.
- [poetry-core](poetry-core.md) — Poetry's PEP 517 build backend, usable without Poetry itself.
- [flit-core](flit-core.md) — Minimal, dependency-free build backend for pure-Python packages.
- [uv-build](uv-build.md) — uv's fast, minimal build backend for pure-Python projects.
