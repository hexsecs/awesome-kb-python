# Penetration Testing

- [mitmproxy](mitmproxy.md) — An interactive TLS-capable intercepting HTTP proxy for penetration testers and software developers.
- [impacket](impacket.md) — A collection of Python classes for working with network protocols, widely used for Windows and Active Directory testing.
- [sqlmap](sqlmap.md) — Automatic SQL injection and database takeover tool.
- [pwntools](pwntools.md) — A CTF framework and exploit development library.
- [sherlock-project](sherlock-project.md) — Hunt down social media accounts by username across social networks.
