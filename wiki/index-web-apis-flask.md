# Web APIs / Flask

- [flask-restx](flask-restx.md) — Fully featured framework for fast, easy and documented API development with Flask.
- [flask-smorest](flask-smorest.md) — A Flask/Marshmallow-based REST API framework with automatic OpenAPI documentation.
- [apiflask](apiflask.md) — A lightweight Python web API framework based on Flask, supporting marshmallow schemas and Pydantic models.
