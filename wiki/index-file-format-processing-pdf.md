# File Format Processing / PDF

- [pypdf](pypdf.md) — A library capable of splitting, merging, cropping, and transforming PDF pages.
- [pymupdf](pymupdf.md) — A fast MuPDF-based library for extracting, rendering, and editing PDFs and other documents.
- [reportlab](reportlab.md) — An open-source library for generating PDFs and graphics.
- [pdfminer.six](pdfminer-six.md) — A community-maintained fork of PDFMiner for extracting information from PDF documents.
