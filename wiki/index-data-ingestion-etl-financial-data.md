# Data Ingestion / ETL / Financial Data

- [yfinance](yfinance.md) — Easy Pythonic way to download market and financial data from Yahoo Finance.
- [akshare](akshare.md) — A financial data interface library, with data provided for academic research only.
- [edgartools](edgartools.md) — Downloads SEC EDGAR filings and XBRL financial statements as structured data.
- [openbb](openbb.md) — A financial data platform for analysts, quants and AI agents.
