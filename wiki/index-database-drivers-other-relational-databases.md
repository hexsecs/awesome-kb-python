# Database Drivers / Other Relational Databases

- [pyodbc](pyodbc.md) — An ODBC bridge for connecting to SQL Server and any other ODBC-accessible database.
- [oracledb](oracledb.md) — The official Python driver for Oracle Database, successor to cxOracle.
- [mssql-python](mssql-python.md) — Official Microsoft driver for SQL Server and Azure SQL, built on ODBC for high performance.
