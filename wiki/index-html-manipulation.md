# HTML Manipulation

- [lxml](lxml.md) — A very fast, easy-to-use and versatile library for handling HTML and XML.
- [beautifulsoup4](beautifulsoup4.md) — Providing Pythonic idioms for iterating, searching, and modifying HTML or XML.
- [xmltodict](xmltodict.md) — Makes working with XML feel like working with JSON.
- [markupsafe](markupsafe.md) — Safely adds untrusted strings to HTML/XML markup.
- [justhtml](justhtml.md) — A pure Python HTML5 parser that sanitizes untrusted HTML by default.
