# Implementations

- [cpython](cpython.md) — Default, most widely used implementation of the Python programming language written in C.
- [micropython](micropython.md) — A lean and efficient Python implementation for microcontrollers and constrained systems.
- [pypy](pypy.md) — A very fast and compliant implementation of the Python language.
- [Cython](cython.md) — Optimizing static compiler for Python.
- [pyodide](pyodide.md) — Python distribution for the browser and Node.js based on WebAssembly.
