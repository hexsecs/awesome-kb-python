# Date and Time

- [zoneinfo](zoneinfo.md) — (Python standard library) IANA time zone support. Brings the tz database into Python.
- [python-dateutil](python-dateutil.md) — Extensions to the standard Python datetime module.
- [dateparser](dateparser.md) — A Python parser for human-readable dates in over 200 language locales.
- [pendulum](pendulum.md) — Python datetimes made easy.
- [whenever](whenever.md) — A modern datetime library, type-safe and DST-safe, in Rust or pure Python.
