# HTTP Clients / General

- [requests](requests.md) — HTTP Requests for Humans.
- [aiohttp](aiohttp.md) — Asynchronous HTTP client/server framework for asyncio and Python.
- [httpx2](httpx2.md) — HTTP/1.1 and HTTP/2 client with sync and async APIs, maintained by Pydantic (httpx fork).
- [urllib3](urllib3.md) — An HTTP library with thread-safe connection pooling, file post, and more.
- [httpx](httpx.md) — A next-generation HTTP client for Python.
