# CLI Development / General

- [argparse](argparse.md) — (Python standard library) Command-line option and argument parsing.
- [click](click.md) — A package for creating beautiful command-line interfaces in a composable way.
- [typer](typer.md) — Modern CLI framework that uses Python type hints. Built on Click.
- [prompt_toolkit](prompt-toolkit.md) — A library for building powerful interactive command lines.
- [cyclopts](cyclopts.md) — Build CLIs from type-hinted functions, with docstring-based help.
