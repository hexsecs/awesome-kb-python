# Image Processing / General

- [pillow](pillow.md) — Pillow is the friendly PIL fork.
- [scikit-image](scikit-image.md) — A Python library for (scientific) image processing.
- [rembg](rembg.md) — A tool to remove image backgrounds.
- [wand](wand.md) — Python bindings for MagickWand, C API for ImageMagick.
- [pyvips](pyvips.md) — A binding for libvips, a fast image processing library with low memory needs.
