- [flask-admin](flask-admin.md) — Simple and extensible administrative interface framework for Flask.

- [sqladmin](sqladmin.md) — An admin interface for SQLAlchemy models in FastAPI and Starlette.
- [django-grappelli](django-grappelli.md) — A jazzy skin for the Django Admin-Interface.
