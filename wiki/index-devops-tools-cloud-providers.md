# DevOps Tools / Cloud Providers

- [boto3](boto3.md) — Python interface to Amazon Web Services.
- [awscli](awscli.md) — Universal Command Line Interface for Amazon Web Services; the PyPI package is v1, in maintenance mode, while v2 ships as AWS's bundled installer.
- [azure-sdk-for-python](azure-sdk-for-python.md) — Microsoft Azure SDK for Python, published as per-service packages.
- [google-cloud-python](google-cloud-python.md) — Google Cloud client libraries for Python, published as per-service packages.
