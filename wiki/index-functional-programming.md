# Functional Programming

- [functools](functools.md) — (Python standard library) Higher-order functions and operations on callable objects.
- [more-itertools](more-itertools.md) — More routines for operating on iterables, beyond itertools.
- [toolz](toolz.md) — A collection of functional utilities for iterators, functions, and dictionaries. Also available as cytoolz for Cython-accelerated performance.
- [funcy](funcy.md) — Fancy and practical functional tools.
- [returns](returns.md) — A set of type-safe monads, transformers, and composition utilities.
