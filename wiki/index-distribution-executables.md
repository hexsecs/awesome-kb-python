# Distribution / Executables

- [pyinstaller](pyinstaller.md) — Converts Python programs into standalone executables (cross-platform).
- [Nuitka](nuitka.md) — Compiles Python programs into high-performance standalone executables (cross-platform).
- [pex](pex.md) — A tool for building self-contained Python executable environments (PEP 441 zipapps).
- [cx-Freeze](cx-freeze.md) — Converts Python scripts into standalone executables and installers for Windows, macOS, and Linux.
