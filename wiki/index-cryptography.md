# Cryptography

- [cryptography](cryptography.md) — A package designed to expose cryptographic primitives and recipes to Python developers.
- [pynacl](pynacl.md) — Python binding to libsodium, a fork of the Networking and Cryptography (NaCl) library.
- [paramiko](paramiko.md) — The leading native Python SSHv2 protocol library.
- [itsdangerous](itsdangerous.md) — Safely pass trusted data to untrusted environments and back.
