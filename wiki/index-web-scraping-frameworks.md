# Web Scraping / Frameworks

- [browser-use](browser-use.md) — Make websites accessible for AI agents with easy browser automation.
- [scrapy](scrapy.md) — A fast high-level web crawling and scraping framework.
- [crawl4ai](crawl4ai.md) — An open-source, LLM-friendly web crawler that provides lightning-fast, structured data extraction specifically designed for AI agents.
- [stagehand](stagehand.md) — A fast and token-efficient browser automation SDK to extract data and perform self-healing actions on web pages.
- [scrapling](scrapling.md) — An adaptive scraping framework whose selectors relocate elements after page changes, with stealth fetchers and spiders.
