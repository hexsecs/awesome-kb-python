# Debugging Tools / Profiler

- [py-spy](py-spy.md) — A sampling profiler for Python programs. Written in Rust.
- [memray](memray.md) — Tracks memory allocations in Python code, native extensions, and the interpreter itself.
- [pyinstrument](pyinstrument.md) — A statistical wall-clock profiler with low overhead and readable call-tree output.
- [scalene](scalene.md) — A high-performance, high-precision CPU, GPU, and memory profiler for Python.
