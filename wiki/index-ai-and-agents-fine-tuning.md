# AI and Agents / Fine-tuning

- [peft](peft.md) — A library for parameter-efficient fine-tuning of large pretrained models.
- [trl](trl.md) — A library for post-training transformer language models with SFT, DPO, GRPO, and other trainers.
- [unsloth](unsloth.md) — Faster, lower-memory LLM fine-tuning, as a Python library or a desktop app.
- [axolotl](axolotl.md) — A framework for fine-tuning and post-training large language models.
