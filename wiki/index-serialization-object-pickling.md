# Serialization / Object Pickling

- [cloudpickle](cloudpickle.md) — Extends pickle to functions, lambdas, and interactively defined classes, for shipping code to remote workers.
- [dill](dill.md) — Extends pickle to serialize almost any object, including closures and interpreter sessions.
