# Machine Learning / Time Series Forecasting

- [prophet](prophet.md) — A tool for producing forecasts for time series with multiple seasonality and trend changes.
- [statsforecast](statsforecast.md) — Fast statistical forecasting models such as ARIMA, ETS, and Theta, compiled with numba.
- [sktime](sktime.md) — A unified scikit-learn-style framework for forecasting and other time-series learning tasks.
- [timesfm](timesfm.md) — A pretrained foundation model from Google Research for time-series forecasting, with non-commercial default weights.
