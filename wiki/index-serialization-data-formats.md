# Serialization / Data Formats

- [msgpack](msgpack.md) — MessagePack serializer implementation for Python.
- [orjson](orjson.md) — Fast, correct JSON library.
- [marshmallow](marshmallow.md) — A lightweight library for converting complex objects to and from simple Python datatypes.
- [msgspec](msgspec.md) — A fast serialization and validation library supporting JSON, MessagePack, YAML, and TOML.
