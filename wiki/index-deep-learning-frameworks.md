# Deep Learning / Frameworks

- [pytorch](pytorch.md) — Tensors and dynamic neural networks in Python with strong GPU acceleration.
- [pytorch-lightning](pytorch-lightning.md) — Deep learning framework to train, deploy, and ship AI products Lightning fast.
- [jax](jax.md) — A library for high-performance numerical computing with autodiff and JIT compilation.
- [keras](keras.md) — A high-level deep learning library with support for JAX, TensorFlow, and PyTorch backends.
- [tensorflow](tensorflow.md) — An end-to-end machine learning platform from Google.
