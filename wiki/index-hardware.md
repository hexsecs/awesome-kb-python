# Hardware

- [pyserial](pyserial.md) — Python serial port access library for Windows, macOS, Linux, and BSD.
- [pynput](pynput.md) — A library to control and monitor input devices.
- [bleak](bleak.md) — A cross-platform Bluetooth Low Energy client for Python using asyncio.
- [jumpstarter](jumpstarter.md) — A hardware-in-the-loop testing framework with a Python client library for automated testing on real and virtual hardware.
