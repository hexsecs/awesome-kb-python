# CLI Development / TUI Frameworks

- [textual](textual.md) — A framework for building interactive user interfaces that run in the terminal and the browser.
- [urwid](urwid.md) — A library for creating terminal GUI applications with strong support for widgets, events, rich colors, etc.
- [asciimatics](asciimatics.md) — A package to create full-screen text UIs (from interactive forms to ASCII animations).
